Анимация 54: Импедансен триъгълник

Последователна RLC верига

Параметри

Индуктивен характер
Наблюдавай:

Променяй R, XL и XC. Импедансният триъгълник показва резултантното реактивно съпротивление X, модула на импеданса |Z| и ъгъла φ.

При индуктивен характер триъгълникът е над реалната ос, а при капацитивен — под нея.

Импедансен триъгълник

R — активно съпротивление X — реактивно съпротивление |Z| — модул на импеданса
Текущи стойности
R = 40 Ω
XL = 80 Ω
XC = 20 Ω
X = XL − XC = 60 Ω
|Z| = 72,11 Ω
φ = +56,31°
cos φ = 0,555

Основни зависимости

X = XL − XC
Z = R + jX
|Z| = √(R² + X²)
φ = atan2(X, R)
cos φ = R/|Z|
sin φ = X/|Z|
tan φ = X/R
Характер на веригата

X > 0: индуктивен характер — токът изостава от напрежението.

X < 0: капацитивен характер — токът изпреварва напрежението.

X = 0: общият импеданс е активен, |Z| = R и φ = 0°.

Ако XL = XC > 0, реактивните съставки се компенсират. Ако и двете са нула, имаме чисто активно съпротивление.
