QR-032 – Трифазна система

Три неподвижни намотки · Метален ламелиран статор · Въртящ се магнит N–S

● Движение
Магнитопровод, намотки и въртящ се магнит Идеализиран двуполюсен генератор · p = 1
Фаза A 0,000 uA / Uбаз
Фаза B +0,866 uB / Uбаз
Фаза C −0,866 uC / Uбаз
Управление

Бутоните спират ротора в характерно положение. При избор „Всички фази“ показанията за потока са за фаза A.

Период T 20,00 ms
Синхронна скорост 3000 min⁻¹
Магнитен поток и моментно напрежение
Наблюдавана фаза: A
Магнитен поток Φ/Φₘ −1,000
Моментно напрежение u/Uₘ 0,000
N е срещу намотка A. Магнитният поток е максимален по модул, а моментното индуцирано напрежение е нула.
uk(t) = −N dΦk dt

Това са нормализирани моментни стойности. Амплитудата е максималната възможна стойност на съответната синусоида, а не нейната текуща стойност.

Трифазни напрежения
uA = Um cos θ
uB = Um cos(θ − 120°)
uC = Um cos(θ − 240°)
Проверка
uA + uB + uC = 0
Моментни напрежения на фазите A, B и C Един курсор, синхронизиран с ротора
Фаза A Фаза B Фаза C
Фаза A — магнитен поток и напрежение Нормализирани към собствените им амплитуди
Φ/Φₘ — магнитен поток u/Uₘ — моментно напрежение

Когато магнитният поток е максимален по модул, моментното напрежение е нула. Когато потокът преминава през нула и се изменя най-бързо, моментното напрежение е максимално по модул.
