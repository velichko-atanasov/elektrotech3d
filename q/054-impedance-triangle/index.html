Анимация 54: Импедансен триъгълник

Последователна RLC верига

Параметри

Индуктивен характер (X > 0)
Наблюдавай:
Променяй R, XL и XC. Триъгълникът автоматично показва общото реактивно съпротивление X, импеданса Z и фазовия ъгъл φ.

Импедансен триъгълник

Текущи стойности

R = 140 Ω
XL = 91 Ω
XC = 0 Ω
X = XL − XC = 91 Ω
Z = 166.98 Ω
φ = 33.02°

Основни зависимости

X = XL − XC
Z = √(R² + X²)
φ = arctan(X/R)
cos φ = R/Z
sin φ = X/Z
tan φ = X/R
Характер на веригата

X > 0: индуктивен характер — токът изостава от напрежението.

X < 0: капацитивен характер — токът изпреварва напрежението.

X = 0: Z = R и φ = 0° — резонансен режим.
