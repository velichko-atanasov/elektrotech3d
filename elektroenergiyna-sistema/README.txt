ЕЛЕКТРОЕНЕРГИЙНА СИСТЕМА — PWA

1. Качете съдържанието на тази папка в GitHub Pages (или друг HTTPS хостинг).
2. Отворете адреса на телефона.
3. Android/Chrome: меню → Install app / Добавяне към началния екран.
4. iPhone/Safari: Share → Add to Home Screen.

Основният файл е index.html.
Service worker кешира приложението за офлайн отваряне. Данни, които се зареждат от външни сайтове, изискват интернет.
