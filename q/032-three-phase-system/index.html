QR-032 – Трифазна система

Въртящ се магнит и три намотки, разположени пространствено на 120°
uA = Uₘ cos(ωt)
uB = Uₘ cos(ωt − 120°)
uC = Uₘ cos(ωt − 240°)
Управление
Моментни стойности
uA = +0.556 p.u.
uB = -0.998 p.u.
uC = +0.441 p.u.
Проверка
+0.556 − 0.998 + 0.441 = -0.000 p.u.
T = 20.00 ms
Магнитът се върти с постоянна скорост. Трите неподвижни намотки са пространствено отместени на 120°. Поради това индуцираните в тях синусоидални напрежения са фазово отместени на 120°.
