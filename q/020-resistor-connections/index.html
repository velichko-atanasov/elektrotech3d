QR-020 – Свързване на резистори

Последователно, паралелно и смесено свързване
Req = R₁ + R₂ + R₃ Req = 100 + 220 + 330 = 650.0 Ω I = UReq I = 12650.0 = 0.0185 A U₁ = IR₁ = 0.0185·100 = 1.85 V    U₂ = 4.06 V    U₃ = 6.09 V P₁ = I²R₁ P₁ = 0.0185²·100 = 0.034 W P₂ = I²R₂    P₃ = I²R₃ P₂ = 0.0185²·220 = 0.075 W    P₃ = 0.0185²·330 = 0.112 W P = UI P = 12·0.0185 = 0.222 W
Резултат:   Req = 650.0 Ω   |   I = 0.0185 A   |   P = 0.222 W
Проверка: P₁ + P₂ + P₃ = 0.222 W = P
При последователно свързване токът е еднакъв през всички резистори, а напрежението се разпределя между тях.
