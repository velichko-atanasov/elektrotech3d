Основни формули от аналитичния модел
Геометрия
Rᵢ² = (x − xᵢ)² + (yₚ − hᵢ)²
Симетричен режим
Uₚₕ = Uᴸ/√3,  φₖ = {0°, −120°, +120°}
Магнитно поле
B̅ₓ,ᵢ = − μ₀I̅ᵢ(yₚ−hᵢ)/(2πRᵢ²)
B̅ᵧ,ᵢ = μ₀I̅ᵢ(x−xᵢ)/(2πRᵢ²)
Резултантно B
Bᴿ = √(|ΣB̅ₓ,ᵢ|² + |ΣB̅ᵧ,ᵢ|²)
Линейни заряди
[q̅] = [P]⁻¹[U̅]
Потенциални коефициенти
Pᵢᵢ = (1/2πε₀) ln(2hᵢ/rᵢ)
Pᵢⱼ = (1/2πε₀) ln(D′ᵢⱼ/Dᵢⱼ)
Електрическо поле
E̅ₓ = Σ q̅ᵢ/(2πε₀) · (x−xᵢ) · (1/Rᵢ² − 1/R′ᵢ²)
E̅ᵧ = Σ q̅ᵢ/(2πε₀) · [(yₚ−hᵢ)/Rᵢ² − (yₚ+hᵢ)/R′ᵢ²]
Резултантно E
Eᴿ = √(|E̅ₓ|² + |E̅ᵧ|²)
Повърхностно поле
Eₛᵤᵣf,max = max Eᴿ(xᵢ+rᵢcosθ, hᵢ+rᵢsinθ)
Корона
Ecor = 21.1·m·δ·(1 + 0.301/√(δrcm))  [kV/cm, rms]
Kcor = Eₛᵤᵣf,max / Ecor
Плъзгачите променят параметрите ръчно; автоматичният режим е премахнат.
