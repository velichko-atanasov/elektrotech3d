При зададените стойности f₀ ≈ 49.98 Hz.

Резонансна характеристика I(f)

Вертикалната линия показва текущата честота. Пикът е около резонансната честота.

Логика на задачата

1. Условие за резонанс: XL = XC.

2. Следователно ω₀ = 1/√(LC).

3. При резонанс: Z = R и I = U/R.

4. За дадените параметри: f₀ ≈ 50 Hz и I ≈ 5,75 A.

В този конкретен пример качественият фактор е приблизително Q ≈ 1, затова напреженията върху L и C са около 230 V. По принцип при по-голям Q те могат значително да превишат захранващото напрежение.

Изчисления стъпка по стъпка

Стъпка 1. Условие за резонанс

XL = XC
ωL = 1/(ωC)
При резонанс индуктивното и капацитивното реактивно съпротивление се компенсират.

Стъпка 2. Определяне на резонансната ъглова честота

ω₀ = 1/√(LC)
ω₀ = 1/√(0.1274 · 0.0000796)
ω₀ = 314.02 rad/s
Резонансната ъглова честота е приблизително 314 rad/s.

Стъпка 3. Определяне на резонансната честота

f₀ = ω₀/(2π)
f₀ = 314.02 / 6.283
f₀ = 49.98 Hz
Получената стойност е практически равна на мрежовата честота 50 Hz.

Стъпка 4. Проверка на реактивните съпротивления при резонанс

XL = ω₀L = 40.01 Ω
XC = 1/(ω₀C) = 40.01 Ω
XL ≈ XC, следователно реактивните съставки взаимно се компенсират.

Стъпка 5. Импеданс при резонанс

Z = √(R² + (XL − XC)²)
Zres = R = 40 Ω
При резонанс импедансът има минимална стойност.

Стъпка 6. Ток при резонанс

Ires = U/R
Ires = 230 / 40
Ires = 5.75 A
Токът е максимален и е във фаза със захранващото напрежение.

Стъпка 7. Напрежения върху L и C

UL = IresXL = 230.0 V
UC = IresXC = 230.0 V
При резонанс фазорите на UL и UC са равни по големина и противоположни по посока, поради което се компенсират във векторната сума.
